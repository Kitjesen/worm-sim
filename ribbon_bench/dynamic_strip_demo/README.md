# 单片钢带释放振动（17 节点）

本算例先对 Sano 钢带施加 0.01 N 中点横向静力载荷并求平衡，再瞬时撤载，以零初速度释放。第一、二及倒数两节点的位置和两端扭转角始终固定在自然形状夹持状态；没有运动刚板、绳索、接触、重力或外部回放轨迹。沿用 CAD 端点与暂定自然抛物线，这还不是实物参数标定。

2026-10-01 实测通过：初始中点位移 **4.722 µm**，两组均出现 **6 次过零**；零输入位移/扭角均为零，夹持无漂移。步长减半后的位移归一化 RMS 差 **1.437%**，最大能量差/初始能量 **7.752%**，分别低于预先设定的 5%／10% 门槛。3000／6000 步实测计算时间 **40.918／82.760 s**，最大动态力残差 **9.995e−8 N**。

## 方程和质量

每步求解 `M(q[n+1]-q[n]-dt*v[n])/dt² + C(q[n+1]-q[n])/dt + grad(E)=0`，然后明确更新 `v[n+1]=(q[n+1]-q[n])/dt`。Newton 的线搜索检查隐式 Euler 增量势；Sano 弹性能、自然应变、几何梯度及 Hessian 沿用 vendor，材料导数使用已核验的 `fast_sano.py` 闭式适配器。`--autodiff` 可恢复原材料自动微分。

平移质量为 `rho*A*Voronoi长度`，边绕自身切线的扭转惯量为 `rho*边长*(I1+I2)`。特意区分惯性截面极二次矩与用于 `G*J` 刚度的矩形 Saint-Venant 扭转常数，未改 vendor。采用杆节点集中质量和边扭转惯量近似，不声称完整三维实体惯性。黏性阻尼是 `C=alpha*M`，默认 `alpha=2 s^-1`：位置项单位 kg/s、扭转项 kg·m²/s。这个演示阻尼未经过实验标定。

## 验证与读取

`summary.json` 是实际运行后的核验记录：零输入静止、夹持不漂移、释放后弹性能向动能转换、机械能不增长、黏性耗散及剩余数值耗散。隐式 Euler 自带数值耗散，不能把总衰减全部解释为材料阻尼。

较细步长的动能峰值为 **2.143e−8 J**，初始弹性能 **2.360e−8 J**；累计黏性耗散 **6.398e−10 J**，剩余数值耗散 **3.958e−9 J**。数值耗散仍约为黏性耗散的 6.2 倍，本结果可以验证释放振动与时间步实现，尚不适合由振幅衰减反求实物阻尼。

`dt.npz` 与 `half_dt.npz` 保存每一个实际时间步的 `time_s`、`q`、`velocity`、动能、弹性能、累计黏性耗散、平衡残差、质量/阻尼对角线与固定自由度。`q` 前 `3N` 项单位 m，后 `N-1` 项为平行输运参考架中的边扭转角（rad）；速度分别为 m/s 与 rad/s。零输入的位置和角度检查分别报告单位，不混为位移。

步长验收：同一时刻的中点位移差 RMS 不超过初始预载位移的 **5%**，机械能最大差不超过初始机械能的 **10%**；两组都必须至少两次过零。不满足时保留真实数据、标记失败并退出，不将比较本身称为收敛。图 `response.png`／`response.svg` 使用物理时间、实际 µm 位移与 µJ 能量，没有放大模型变形或倒放静态帧。

## 运行

工作目录为 `ribbon_bench`，无需硬编码盘符：

```powershell
.\.venv\Scripts\python.exe dynamic_strip.py --output dynamic_strip_reproduce
```

默认比较 `dt=5 µs` 与 `2.5 µs`，释放时长 `15 ms`，约覆盖三个主导振动周期（预载的主导线性频率约 193 Hz）。正式测得的数值、步数、耗时和代码 SHA-256 以随附 `summary.json` 为准；尚无该文件时代表尚未完成验证。它仅验证单片动力学，不能替代整个机器人的刚柔接触耦合。
