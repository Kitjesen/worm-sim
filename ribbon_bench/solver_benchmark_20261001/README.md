均为8片、每片33节点、25保存状态的完整绳驱往返路径。40 mm/30°是生成绳长的指令几何，实际峰值仍约47.585 mm/12.862°。计时含路径求解与检查点序列化，排除导入、初始化及绘图。默认线程和单线程不是同时运行；单线程仅一对，不给统计稳定性承诺。不能将本结果外推为动态、接触或GPU性能。

三次默认线程逐帧对照的节点分量最大差为1.34e-12 m，后板支承力分量最大差1.20e-8 N，绳张力差5.05e-11 N。单线程最大节点差2.15e-12 m。所有候选状态满足原自由节点和隔板平衡残差阈值。这是数值一致性，不是实物精度。
