# Current Artifacts

This directory contains current demo-facing and paper-facing outputs. New
current videos should use descriptive names rather than implementation version
names.

## Current Sets

- `flat_omni_v29_long15/`: 15 s HD flat six-direction videos for the current
  V29 viewable policy. This is the set to show first when demonstrating the
  robot because each direction runs long enough to expose drift.
- `flat_omni_v29_hd/`: shorter 6 s HD flat six-direction V29 videos.

The top-level video index is `record/VIDEO_INDEX.md`.
