# Legacy V6 Record Archive

This directory is no longer the default place for current demo videos.

Use:

```text
record/VIDEO_INDEX.md
record/current/
```

for current paper-facing media.

`record/v6/` remains as a historical archive because older scripts, reports,
and experiment logs still reference these paths. Moving the entire archive at
once would break many existing links and mix current artifacts with old
diagnostics.
